## 1. 最大の発見：集客は機能している。漏れているのは受け皿

### 無料鑑定250件 → LINE登録70人 → 有料14件

この3段の数字が、事業の全てを説明しています。

**月200〜300件の無料鑑定をこなせている** ということは、需要も露出も十分にあるということです。占い師として活動2ヶ月で月250件の申込が来るのは、集客が機能している証拠です。

問題は、その250件が**LINEに入っていない**こと。

```
無料鑑定 250件
    ↓ 28%（月70人相当）  ← ここが最大の漏れ口
LINE登録 70人
    ↓ 7%
LINE経由の有料 5件
```

Threads上のDM・リプライで無料鑑定が完結しているため、250人と接触しているのに手元に残っているのが70人。**残りの180人は跡形もなく消えています。**

### 転換率の認識と実測にズレがあります

体感では「1割以上2割未満」ですが、分母を月の無料鑑定件数（250件）で取ると実測は**5.6%**（14件／250件）。さらに、ココナラ9件は無料鑑定由来ではない可能性が高いので、無料鑑定→有料の実線は **5件／250件 = 2%** かもしれません。

ここを正確に測ることが最初の仕事です。ただし打ち手は測る前から確定しています。

### 時間の使われ方

無料鑑定250件を1件12分でこなしても**月50時間**。これに対するリターンが、最大でも月28,000円。

> 月160時間 ÷ 月商28,000円 = **時間単価175円**

前回「商品が悪いのではなく時間の行き先の問題」と書きましたが、実データを見ると診断はもっと限定的です。

> **集客は問題ない。受け皿（リスト化・単価・転換）だけが問題。**

これは良いニュースです。一番作るのが難しい「人が集まる状態」がすでにできているので、手を入れるのは仕組み側だけで済みます。

## 2. 3つのレバー（インパクト順）

### レバー1：無料鑑定の申込窓口をLINEに一本化する 【最優先】

**これ1つでリストが月+200人になります。**

現在：Threads の投稿 → DM・リプライで無料鑑定 → 気に入った人が LINE 登録（28%）

変更後：Threads の投稿 → **「無料鑑定は公式LINEで受け付けています」** → LINE登録 → LINE内で無料鑑定

これだけで250件の接触がそのままリストになります。登録率は8割前後まで上がる想定。

- 1ヶ月目：270人
- 3ヶ月目：670人
- 6ヶ月目：1,270人
- 12ヶ月目：2,470人

Phase 3 で必要な1,800〜2,500人に、8〜11ヶ月目で届きます。**広告費ゼロで。**

Threads の DM で直接鑑定するのを止めるだけです。実装コストはゼロ、今日からできます。

### レバー2：単価を2,000円 → 平均5,000円に組み替える

同じ14件で 28,000円 → 70,000円。

2,000円を5,000円に値上げするのではなく、**別の商品として出す**のがコツです。既存顧客に「値上げしました」と言うと離れますが、「新しいメニューを作りました」なら離れません。

### レバー3：LINE内の転換率を 7% → 20% にする

ステップ配信を入れるだけ。70人 → 14件になります。

## 3. 「大アルカナ22枚」を弱みではなく旗にする

鑑定歴2ヶ月・大アルカナのみ。ここは隠すより看板にします。

### 打ち出し

> **「大アルカナ22枚だけで、関係の本質を読む」**

- 78枚使わないことを「削ぎ落とし」として提示する
- **できないことを先に明言する** — 細かい時期や第三者の詳細は読まない。これが信頼になります
- 訴求軸は「当たる」ではなく **「整理がつく／決められる」**

鑑定歴2ヶ月で「当たる」を訴求するのは危険です。実績で殴られたときに返せません。「あなたの中で答えが決まる」という訴求なら、鑑定歴は関係なくなります。そしてペルソナ（何度も友人に相談して呆れられている人）が本当に欲しいのは、当たる予言ではなく決断の後押しです。

### この旗は Phase 3 の講座に直結します

一般向けタロット講座の最大のハードルは「78枚も覚えられない」です。

> **「22枚だけ覚えれば読めるようになる講座」**

これは学ぶ側の参入障壁を消します。教える側の鑑定歴が短いことも、「22枚に絞ったから短期間で読めるようになった」という物語として機能します。

## 4. ジャンルとペルソナ（実績で裏付け済み）

相談は恋愛8割・仕事2割、基本は人間関係。仮説どおりだったので設計はそのまま使います。

### ジャンル：恋愛の中でも「進まない関係」

片思いが半年以上進まない／告白されないまま関係が続いている／音信不通／別れた相手を諦められない。

選ぶ理由：需要量が最大・悩みが深く単価を上げられる・状況が動き続けるのでリピートが自然に起きる（リピート率2割弱がすでに出ているのは、この性質の証拠です）。

### メインペルソナ

> **28〜38歳・女性・会社員または専門職・年収300〜500万円**
>
> 好きな人との関係が半年以上進んでいない。または別れた相手を忘れられない。
> 友人には何度も相談して、もう呆れられている。親には言えない。
> 夜、寝る前にスマホで TikTok ライブや占い動画を見ている。
> すでに他の占い師に1〜3回は見てもらったことがある。当たったこともあるが、結局状況は変わっていない。

**この人が買っているのは「答え」ではなく「肯定と伴走」です。** だから単発より継続商品が刺さる。これが月50万円到達の設計上の核になります。

### サブペルソナ（Phase 3 の講座用）

> 30〜45歳・女性・タロットに興味があるが78枚が覚えられず挫折した。
> 自分や身近な人を占えるようになりたい。あわよくば副業にしたい。

## 8. 動線と LINE ステップ配信

### 改善後の動線

```
[Threads 投稿 / TikTokライブ]
        ↓ 「無料鑑定は公式LINEで受付中」 ← レバー1
   [公式LINE 登録]  月+200人
        ↓ 無料1枚引き（LINE内・未完了で終わらせる）
        ↓ ステップ配信 7通
 [1問1答 2,980円 / 3枚読み 5,980円]  目標転換率 8%
        ↓ 納品時に案内
 [深掘りセッション 9,800円 → 決着セッション 19,800円]  目標 25%
        ↓ 7日フォロー終了時に案内
[月いち伴走会員 4,980円] or [22枚講座 39,800円]  目標 30%
```

### 無料鑑定の設計（3つのルール）

1. **窓口はLINEのみ。** Threads のDMで完結させない
2. **1件3分・80字以内。** 大アルカナ1枚だけ引く
3. **未完了で終わらせる。** 締めの型を固定する：

> 「◯◯のカードが出ています。ただ、**なぜそうなっているのか**まではこの1枚では見えません。そこを深く見たいときは、メニューからお選びください。」

「解決」させると次を買う理由が消えます。月250件やっていて有料14件なのは、ここが原因です。

### TikTokライブ

週3回・21:00〜22:30で固定（視聴習慣を作る）。コメントから1枚引きを公開でやり、「個別で深く見たい人はプロフィールのLINEから」を配信中に3回言う。フォロワー290人で月250件の無料鑑定が来ているので、ライブの回数を増やすほど直線的に伸びる段階です。

### LINEステップ配信 7通（渡邊さんが自作・最優先）

| 日 | 内容 | 目的 |
|---|---|---|
| 1 | 登録御礼＋深ひとみの自己紹介（なぜ22枚なのか／自分の失敗談） | 人として認識させる |
| 2 | 大アルカナ22枚で何がわかって、何がわからないか | 期待値調整＝信頼になる |
| 3 | 「進まない関係」に共通する3つのパターン | ペルソナに刺す価値提供 |
| 4 | お客様の変化ストーリー 1本 | 証拠 |
| 5 | よくある質問（怖くないか／当たるとは／料金） | 不安の除去 |
| 6 | 1問1答タロット 2,980円の案内（初回限定・48時間） | オファー |
| 7 | リマインド＋「使わなくても大丈夫です」の一言 | 押し売り感の除去 |

### ココナラの再定義：止めずに「単価の実験場」にする

ココナラ9件 vs LINE経由5件。**現状はココナラの方が売れています。** ここは検索需要があるので、捨てるのは損です。

- **電話相談のみ停止**（手数料6割は割に合わない）
- テキスト鑑定は継続（手数料22%）
- 役割を2つに変更：**①レビューを100件積む ②新価格が売れるか試す実験場**

5,980円のテキスト鑑定がココナラで売れるなら、LINE側でも自信を持って出せます。逆に売れなければ価格か訴求を直す。**ココナラは検証コストの安いテスト環境**として使ってください。

規約上ココナラ内から直接LINEへ誘導するのはNGなので、納品物に「深ひとみ」の名前と世界観を残し、指名検索させる導線にします。

## 9. 開業と法人設立：今の法人化は反対です

**月商28,000円で法人を作ると、固定費が売上を食います。**

| 項目 | 金額 |
|---|---|
| 法人住民税 均等割（赤字でも発生） | 年7万円 |
| 設立費用（合同会社） | 6〜10万円 |
| 設立費用（株式会社） | 20〜25万円 |
| 税理士費用 | 年15〜30万円 |
| **年間固定費** | **28〜60万円** |

現在の年商見込み（34万円）とほぼ同額です。

### 正しい順序

**ステップ1：今週 — 開業届＋青色申告承認申請（費用0円）**

個人事業主として開業。e-Tax または税務署で同時提出できます。青色申告特別控除65万円が使えるようになるので、これは最速でやる価値があります。開業日から2ヶ月以内に青色申告承認申請を出す必要があるので、期限に注意。

**ステップ2：今月 — 屋号付きの事業用口座を開設**

個人事業主名義で開設できます。屋号付き口座に対応している銀行（GMOあおぞらネット銀行、PayPay銀行など）を選ぶと「深ひとみ」名義で受け取れるので、信頼面でもプラスです。開業届の控えが必要なのでステップ1の後。

**ステップ3：Phase 3 達成後 — 法人化を検討**

検討ラインは**年間所得（売上−経費）が500万円を超えたとき**。月商50万×12ヶ月＝年商600万、経費を引いて所得400〜500万。つまり**月50万が安定してから**です。

法人設立予定・事業用口座開設予定というお話でしたが、**口座は今すぐ、法人は12ヶ月後**が正しい配分です。
