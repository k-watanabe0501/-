## 1. 診断：買われない3つの理由

### 理由① 無料鑑定と500円商品が、中身も納期もほぼ同じ

| | 無料個人鑑定 | 初回お試し鑑定 500円 |
|---|---|---|
| 質問数 | **1つ** | **1つ** |
| カード | **1枚引き** | **1枚引き** |
| 納期 | 10分〜12時間以内 | 通常12時間以内 |
| 入力項目 | 6項目 | **7項目**（注文番号が追加） |
| 手順 | **1ステップ** | **5ステップ** |

**中身は同じで、有料のほうが手間が多い。** この条件で500円を払う理由はありません。

初回お試し鑑定は「お金を払う体験をさせる」ための入口商品として正しい設計です。一度でも払った人は2回目のハードルが劇的に下がる。でも**いまは無料版と差がないので、その役割を果たしていません。**

### 理由② 有料のほうが、手続きが重い

無料は「相談内容を1通送るだけ」。有料は「決済 → 完了画面をスクショ → 注文番号を書き写す → 相談内容を送る」。

実データでは50代・60代のお客様が複数います。**スクリーンショットの送信と注文番号の書き写しは、この層にとって実際のハードルです。** 摩擦が無料と有料で逆転しています。

### 理由③ 「今買う理由」がない

メニューは常設なので、いつでも買えます。いつでも買えるものは、今買いません。

そして実データを見ると、お客様は**自分から戻ってきています。**

| 相手 | 1回目 | 2回目 | 間隔 |
|---|---|---|---|
| あやの（23） | 8/6 無料 | 9/3「今月中に彼と復縁できるか占って欲しいです！」 | 28日 |
| りな（29） | 8/28 無料 | 9/1「今の私に必要なメッセージお願いします」 | 4日 |
| 吉田香（50代） | 同日1回目 | 同日2回目「今後は、どの様な感じになるのかな?」 | 数分 |

**戻ってきた人が、一番売れる人です。** でも現状は、戻ってきても全員無料で受けています。応答メッセージには「ご相談はお一人様1件」と書いてあるのに、運用で守られていません。

## 2. 価格が低すぎる

平均単価2,000円は偶然ではありません。**メニューの設計どおり**です。

### 特に「チャット鑑定 質問5つまで 2,000円」が致命的

質問5つに答える作業は、無料鑑定（質問1つ）の5倍です。現状の無料鑑定の回答が800〜1,000字なので、質問5つなら3,000字を超えます。所要は1時間前後。

> **1時間かけて2,000円。時間単価2,000円。**

これが月商28,000円 ÷ 月160時間 ＝ **時間単価175円**の正体です。

### 電話鑑定は悪くないが、主力になっていない

電話30分4,000円は、準備と記録を入れて1時間とすると時間単価4,000円。テキストよりずっと良い。**でもこれが売れていない**（平均単価2,000円ということは、2,000円の商品が主に売れている）。

理由は、電話は心理的ハードルが高いのに、**価格が安いせいで「大したことない商品」に見えている**からです。15分2,000円と30分4,000円が並んでいると、「お試し」の延長に見えます。

### 価格改定案

| 商品 | 現在 | 改定 | 変更点 |
|---|---|---|---|
| 初回お試し鑑定 | 500円 | **500円のまま** | **中身を3枚引きに変更**（無料との差を作る） |
| チャット鑑定 | 質問5つ 2,000円 | **質問1つ 2,980円** | 質問数を絞る |
| （新設）じっくり鑑定 | — | **質問3つ 5,980円** | 元のチャット鑑定の位置 |
| 電話鑑定 15分 | 2,000円 | **廃止** | 短すぎて価値が伝わらない |
| 電話鑑定 30分 | 4,000円 | **6,000円** | |
| （新設）電話鑑定 45分 | — | **9,800円** | 35歳以上の主力 |
| （新設）深掘りセッション 60分 | — | **19,800円** | ＋鑑定書PDF＋7日間LINEフォロー。Phase 2から |
| （新設）月いち伴走会員 | — | **月4,980円** | Phase 2から |

**値上げではなく、商品の作り替えです。** 「チャット鑑定2,000円」を「質問1つ2,980円」に変えるのは、単価が1.5倍になると同時に**作業量が5分の1になります**。実質的な時間単価は7倍です。

## 3. 無料鑑定を「1枚引き・80字」に縮める

いま無料鑑定で800〜1,000字の回答を書いています。これが有料商品の存在意義を消しています。

| | 現在 | 改定 |
|---|---|---|
| 無料個人鑑定 | 1枚引き・800〜1,000字 | **1枚引き・80〜150字** |
| 初回お試し鑑定 500円 | 1枚引き・800〜1,000字 | **3枚引き・800字**（状況と3ヶ月の流れ） |
| チャット鑑定 2,980円 | 質問5つ・3,000字 | **質問1つ・3枚引き・1,500字＋行動の提案** |

無料の回答は、この型に固定します。

> 「◯◯のカードが出ています。（結論を1〜2文）
> ただ、**なぜそうなっているのか**まではこの1枚では視えません。
> そこを深く視たいときは、メニューの初回お試し鑑定（500円）でカード3枚から視させていただきます🌙」

**「解決」で終わらせず「未完了」で終わらせる。** 現状は「今すぐ動く必要はありません」「焦らず」で締めていて、緊急性を自分で消しています。

## 4. 購入フローを5ステップから3ステップへ

### 現在（5ステップ）

1. メニューを選択
2. STORESで決済
3. **完了画面をスクショして送信**
4. **注文番号を書き写して**相談内容を送信
5. 鑑定結果

### 改定（3ステップ）

1. メニューを選択
2. STORESで決済
3. LINEに「完了しました」＋相談内容を送信 → 鑑定結果

**スクリーンショットの送信と注文番号の書き写しをなくします。** 照合は渡邊さんがSTORESの管理画面でやれば済みます。お客様に事務作業をさせない。

さらに、STORESの購入フォームに**備考欄があるなら、そこに相談内容を書いてもらう**運用にすれば2ステップになります。決済と同時に相談が届きます。

### 決済はSTORESに統一する

まちゃさん（60代）のトークに Stripe Checkout のリンクが送られていて、「You need to enable JavaScript to run this app.」というエラー表示になっていました。メニュー導線はSTORESなので、**Stripeは使わずSTORESに統一**してください。二重管理はミスの元です。

## 5. 2回目以降は有料にする

これが**単独で一番売上を動かす打ち手**です。

実データで、月250件の無料鑑定のうち何割が2回目以降かは分かりませんが、確認した12人中3人が2回目を無料で受けています。**25%です。**

### ルール

- 無料個人鑑定は**お一人様1回のみ**（すでに応答メッセージに書いてある。守るだけ）
- 2回目以降の依頼が来たら、**その場で初回お試し鑑定（500円）を案内する**

### 案内の文面

```
ご相談ありがとうございます🌙

無料の個人鑑定はお一人様1回とさせていただいておりまして、
2回目以降はメニューからお選びいただく形になります。

▼ 初回お試し鑑定　500円
　カード3枚で、今の状況とこの先3ヶ月の流れを視ます

▼ チャット鑑定　2,980円
　ご質問1つを、カード3枚でじっくり視て
　これからの動き方までお伝えします

▼ 電話鑑定 30分　6,000円
　お声を聞きながら、その場で引いてお答えします

メニューからお選びいただけます🌙
```

戻ってきた人は、**すでにひとみさんの鑑定を気に入っている人**です。ここで500円を払ってもらえれば、次からは有料が当たり前になります。

### 月初の無料配布も同じ問題

毎月1日に「今月の流れ」を希望者に個別で無料鑑定しています。これは月いち伴走会員（4,980円）と中身が重なるだけでなく、**「無料でまた視てもらえる」という期待を毎月更新しています。**

配布自体はリスト維持に効いているので止めません。**個別鑑定をやめて、全員共通の「今月の流れ」1本を一斉配信する**形に変えてください。

| | 無料（月初配布） | 月いち伴走会員 |
|---|---|---|
| 内容 | 全員共通の「今月の流れ」1本 | その人個人を視た鑑定 |
| 形式 | 一斉配信 | 個別 |
| 名前の呼びかけ | なし | あり |

| 千紘（40代後半） | 「またご相談したいときは**チャット鑑定からお願いしよう**と思います」 |
| ゆき（35） | 「また、悩みが出てきたら**真っ先にひとみさんにご相談しようと決めました**」 |

### 対応を3層に分ける

| 層 | 判定基準 | 対応 | 工数 |
|---|---|---|---|
| **A** | 35歳以上／相談文が長い／具体的な相手がいて関係に歴史がある | 事前ヒアリング1往復＋丁寧な無料鑑定＋**電話鑑定を名指しで勧める** | 15分 |

| **C** | 相手が特定されていない／短文 | 定型80字＋メニュー誘導 | 2分 |

月250件で、**50時間 → 17時間**。33時間が空きます。

判定は受付時点でできます。相談フォームの回答を見れば、年齢も文量も相手の有無もわかります。

### A層には電話を名指しで勧める

35歳以上の買う層に、テキスト商品を勧めても弱い。**電話鑑定を名指しで勧めてください。**

> 「今回のご相談は、文字でお伝えするには少し込み入っているように感じました。**お電話でお話ししながらのほうが、お力になれると思います。**メニューの電話鑑定30分（6,000円）からお選びいただけます🌙」

まさとさん（33・男性）の相談文は12件で最長でした。千紘さん（40代後半）の不倫相談も同様です。**こういう案件はテキスト1往復では収まりません。** 電話に誘導するのが、お客様にとっても正しい。

## 7. 顔出しライブが信頼の源泉

千紘さん（40代後半）の一言が、集客構造を説明しています。

> 「**LIVEでお顔が見れたので信頼して相談できると思いました。**」

40代後半・50代・60代は、確認できた範囲で**全員LIVE経由**。ゆきさん（35）も「TikTokで世界のカードが出たとのことでしたが」とライブの内容を引用しています。一方、TikTokの「投稿」から来たのは えみさん（20）と りなさん（29）でした。

> **ライブは買う層を連れてくる。投稿は量を連れてくる。**

週3回では足りません。**週5回に増やしてください。** 3層振り分けで空いた33時間のうち12時間を回せば成立します。

そして千紘さんが信頼したのは「顔が見えたこと」であって、的中ではありません。ライブでは**当てにいかず、人柄を見せる**ほうが売上につながります。

## 8. ペルソナ

### メインペルソナ＝買う層

> **35〜60代・女性**
>
> 20年、30年という単位の関係の歴史を抱えている。復縁、不倫、あるいはサークルや職場で出会った同世代の相手。
> 若い頃の恋愛と違って「残り時間」の感覚があるから、答えを先延ばしにしたくない。
> 友人にも家族にも言えない。
> TikTokライブでひとみさんの顔を見て、「この人なら話せる」と思ってLINEを追加した。
> **お金は払える。** むしろ「無料で申し訳ない」と感じている。

実例：千紘さん（40代後半・20年越しの不倫関係・借金）、吉田香さん（50代・サークルの同世代）、まちゃさん（60代）、ゆきさん（35・「自己肯定感」「執着を手放す」という語彙で話す）。

**この層が買っているのは「答え」ではなく、誰にも言えない話を聞いてもらう場所と、決断の後押しです。**

### サブペルソナ＝量の層

> **19〜33歳・男女**
>
> 片思い、復縁、結婚時期、友達以上恋人未満。
> 無料鑑定の主要な受け手。リスト形成には貢献するので切らない。工数は最小化する。

### 男性客について

まさとさん（33）の相談文は12件中で最も長く、最も具体的でした。質問も本質的です。

> 「復縁することができるのか、**またはそれが正解なのか**」

占いの結果ではなく、決断の後押しを求めています。男性客は少数ですが、**関与度が高く、電話・セッション型商品と相性が良い層**です。排除しないでください。

### 不倫案件について

実際に来ています（千紘さん）。方針は **看板には掲げない。来た案件は受ける。** 40代以降の「誰にも言えない関係」の相談は買う層の中核なので、ここを断ると買う層を断ることになります。

### ブランドの核

プロフィールにすでにこの言葉があります。

> 「はじめまして。**タロットカードの翻訳者**です。カードは今のあなたに必要なメッセージを映すもの。私はそのメッセージを、できるだけありのまま言葉にしてお届けします。」

**「当てる人」ではなく「訳す人」**という立て方が、鑑定歴2ヶ月という事実とも、大アルカナ22枚だけという制約とも矛盾しません。訴求軸は「当たる」ではなく**「整理がつく・決められる」**。崩さずに使ってください。

## 17. 今週やる4つ

### 1. 無料鑑定を80字に縮める
いま800〜1,000字書いています。これが有料商品の存在意義を消しています。**結論1〜2文＋「深く視るならメニューから」**の型に固定してください。

### 3. 2回目以降の依頼に、有料案内を送る
確認した12人中3人が2回目を無料で受けています。**戻ってきた人が一番売れる人です。** 文面は設計書の §5 にあります。

### 4. 購入フローを3ステップに減らす
スクリーンショットの送信と注文番号の書き写しをなくす。**50代・60代のお客様に事務作業をさせないでください。** 照合は渡邊さんがSTORESの管理画面でやれば済みます。
